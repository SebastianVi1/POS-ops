# Reconcile replacement recovery before reopening checkout

A backup can omit sales already completed on a failed computer, while the cloud may contain only some of those later records. A replacement installation restores the backup, replays available cloud records, and requires manager reconciliation of the remaining gap before enabling checkout. The old writer must be retired and the replacement uses a new receipt generation, accepting recovery downtime to protect inventory, cash, and receipt identity.

Offline records absent from both backup and cloud are not automatically recoverable. A disconnected old computer cannot be remotely prevented from operating, so physical retirement and exclusive operational use are part of the replacement procedure.
